# songloft-org/songloft#518：歌单浏览

[Issue](https://github.com/songloft-org/songloft/issues/518) 请求歌名首字母、手机首页宫格或纵向浏览及数量；用户补充要求 Lynx 与 Flutter 效果类似，并加入大屏宫格设置。[English](../en/project/issue-518.md)。

## 行为

- 首页菜单提供自动、横向滑动、宫格、纵向列表；所有布局显示歌曲数量。自动保持窄屏轮播、宽屏宫格。
- 设置 → 外观 → 首页歌单布局提供每行自动 / 2–6 个、显示 1–4 行 / 全部。按实际区域宽度减列，包括桌面左右分区；行数预算使用减列后的数量。各布局按预算补足分页，纵向列表和全部行数最多每区 200 个，完整集合走「查看全部」。选择保存在本机，迟到读盘不覆盖新选择。
- 两端设置 → 外观提供「显示电台区块」，默认开启、仅保存在本机；关闭后首页整个「我的电台」区块隐藏，忽略该区加载/错误与自动续拉。Lynx 大屏歌单区使用整行宽度，单区自动六列（仍按可用宽度减列），可从设置重新开启。
- 歌单详情保留序号，连续同首字母仅在第一行显示字母；中文拼音、英文大写，其他文字、数字、符号为 `#`。不修改歌名、排序或播放索引，多选与手动排序保留原交互。
- 虚拟列表外新增可拖动滚动条，气泡显示首字母、当前歌名和序号 / 总数；拖到未加载位置时逐页续拉，普通打开不拉取整单。空页、错误、离开页面和筛选变化停止原定位。
- `pinyin-pro` 为纯 JS 依赖，已在应用开源许可页登记；未修改原生模块和后端接口。
