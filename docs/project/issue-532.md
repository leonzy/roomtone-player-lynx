# #532：首页内置收藏卡片显示

关联 [songloft-org/songloft#532](https://github.com/songloft-org/songloft/issues/532)，日期 2026-10-21；[English](../en/project/issue-532.md)。

「设置 → 外观 → 首页布局」新增「在首页显示收藏」「在首页显示电台收藏」，默认开启，按服务器身份 URL 和登录账号保存在本机，不参与服务器偏好同步。仅过滤首页卡片，不改变曲库入口、收藏功能、歌曲成员或 `hidden` 标签；整块电台显示仍由原开关控制，并保留独立的电台收藏选择。

识别依据为 `built_in` 与内置歌单 ID，同名普通歌单不会被排除。过滤发生在布局数量截断前；续拉按可见卡片数量补齐，游标仍按原始分页长度防止空页循环。切账号立即切换偏好，写入按账号串行化并保留另一个开关的值；跨账号的迟到读取不能串状态。订阅使用 ReactLynx effect 与 store 的 vanilla API。
